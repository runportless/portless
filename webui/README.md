# Embedded web UI

This directory packages the production web interface for embedding in the
Portless executable. The frontend source, development tooling, and tests live
in [`../web`](../web).

The contents of [`dist`](dist) are generated by the Vite build. Do not edit,
rename, or remove files in `dist` manually. Make UI changes in `../web/src`,
then regenerate the embedded assets from the repository root:

```sh
make web
```

[`embed.go`](embed.go) is the small Go wrapper that embeds the generated
`dist` directory into the Portless binary.
