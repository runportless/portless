# Product captures

These images are direct captures of a running Portless control plane. The
topology GIF was recorded from an isolated `store/local` environment while
real `curl` requests crossed checkout, inventory, and orders. The remaining
screenshots were captured from an isolated `showcase/local` environment with
three live services, generated traffic, one recording, one mock profile, and
one scoped fault.

Do not replace these files with frames or stills from the explainer video. When
the product UI changes, refresh the screenshots from a live application state
and keep the page's alternative text aligned with what the capture shows.
