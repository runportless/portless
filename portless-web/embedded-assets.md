# Embedded web UI

This product contains the frontend source, development tooling, tests, and the
production web interface embedded in the Portless executable. Application code
lives in [`src`](src), and browser end-to-end tests live in [`e2e`](e2e).

The contents of [`dist`](dist) are generated by the Vite build. Do not edit,
rename, or remove files in `dist` manually. Make UI changes in `src`,
then regenerate the embedded assets from the repository root:

```sh
make web
```

[`assets.go`](assets.go) is the small Go wrapper that embeds the generated
`dist` directory into the Portless binary.
