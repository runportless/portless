# Portless brand assets

The SVG files are the editable masters. PNG exports use the canonical Portless
teal (`#31c3b5`), ink (`#071012`), and light text (`#e5ecee`).

## Logo lockups

- `portless-logo-dark.*` uses dark lettering for light backgrounds.
- `portless-logo-light.*` uses light lettering for dark backgrounds.
- Each lockup is available at 1200×300, 600×150, and 300×75 pixels.

## Mark and GitHub icon

- `portless-mark.svg` is the transparent square master. PNG exports are
  available at 512, 256, 128, and 64 pixels square.
- `github-org-icon-500x500.png` is the upload-ready GitHub organization icon.
  `github-org-icon.svg` is its editable master.
